# Delivery Checklist for the Pro Model

Before returning v2, verify that the delivery contains:

- [ ] Complete source directory
- [ ] Complete source ZIP
- [ ] Build instructions
- [ ] Migration instructions
- [ ] V2 audit
- [ ] Test report
- [ ] Known limitations
- [ ] v2.1 backlog
- [ ] Exercise inventory
- [ ] Renderer inventory
- [ ] Deepnote mapping/template
- [ ] Git Visual Lab documentation
- [ ] Terminal Lab documentation
- [ ] No secrets or credentials
- [ ] No hidden dependency on Netlify Functions or cloud accounts
- [ ] Existing v1 state migration tested
- [ ] Representative screenshots if the environment allows them

The Pro model should report what is genuinely implemented versus planned. Do not mark a P1/P2 feature complete unless the actual source and tests support it.
